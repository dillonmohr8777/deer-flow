# Rule 59A-36.014(2), F.A.C.
Section: 59A-36.014 Physical Plant Standards
Official: https://www.flrules.org/gateway/ruleNo.asp?id=59A-36.014

[Rule 59A-36.014(2), F.A.C.] EXISTING FACILITIES.
[Rule 59A-36.014(2)(a), F.A.C.] An assisted living facility must comply with the rule or building code in effect at the time of initial licensure, as well as the rule or building code in effect at the time of any additions, modifications, alterations, refurbishment, renovations or reconstruction. Determination of the installation of a fire sprinkler system in an existing facility must comply with the requirements described in Section 429.41, F.S.
[Rule 59A-36.014(2)(b), F.A.C.] A facility undergoing change of ownership is considered an existing facility for purposes of this rule.
