# Section 429.076(2), F.S.
Section: 429.076 Memory care services license
Official: http://www.leg.state.fl.us/statutes/index.cfm?App_mode=Display_Statute&URL=0400-0499/0429/Sections/0429.076.html

[Section 429.076(2), F.S.] By June 1, 2027, the agency shall adopt rules to provide minimum standards for memory care services licenses. Such rules must include, but are not limited to:
[Section 429.076(2)(a), F.S.] Policies and procedures for providing memory care services.
[Section 429.076(2)(b), F.S.] Standardized admittance criteria for memory care residents.
[Section 429.076(2)(c), F.S.] The minimum level of care, services, and activities that must be provided to memory care residents.
[Section 429.076(2)(d), F.S.] Minimum training requirements for staff at a facility with a memory care services license, which must meet or exceed training requirements established in s. 430.5025.
[Section 429.076(2)(e), F.S.] Safety requirements specific to memory care residents, including, but not limited to, requiring a memory care services licensee to maintain at least one awake staff member to be on duty at all hours.
[Section 429.076(2)(f), F.S.] Physical plant requirements for a facility, or parts of a facility as specified by the licensee, serving memory care residents.
[Section 429.076(2)(g), F.S.] Requirements for contracts with memory care residents which, in addition to the requirements established by s. 429.24, must require a memory care services licensee to specify the memory care services that will be provided to the memory care resident.
[Section 429.076(2)(h), F.S.] Specified terms or terminologies that a facility may not use in its advertising without obtaining a memory care services license. Such terms include, but are not limited to, memory care, memory care facility, memory care services, memory care residents, dementia care, dementia care facility, Alzheimer’s care, and Alzheimer’s care facility. A facility that is not licensed to provide memory care services may advertise the supportive services, as defined in s. 429.02, it provides for persons with Alzheimer’s disease and related dementias so long as such advertisements do not use any terms or terminology prohibited by the agency’s rules pursuant to this subsection, such advertisements do not make any claim that the facility provides memory care services, and the facility maintains a copy of such advertisements in its records. The agency shall examine all such advertisements in the facility’s records as part of its licensure renewal procedure.
[Section 429.076(2)(i), F.S.] Requirements that a facility must meet to continue to serve memory care residents without obtaining a memory care services license pursuant to subsection (5).
