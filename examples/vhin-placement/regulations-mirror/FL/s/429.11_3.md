# Section 429.11(3), F.S.
Section: 429.11 Initial application for license
Official: http://www.leg.state.fl.us/statutes/index.cfm?App_mode=Display_Statute&URL=0400-0499/0429/Sections/0429.11.html

[Section 429.11(3), F.S.] If the applicant is a community residential home, the applicant must provide proof that it has met the requirements specified in chapter 419.
