# Workflow framework and browser boundary

`app/gateway/workflow_adapters.py` transports model calls for the existing workflow service; it owns no queue. Native LangGraph remains the durable controller. Optional CrewAI/Mastra/DeepAgents/Agno/Inngest workers make one admitted handoff using private JSON Lines; package pins/wire protocol/extension requirements are in `workers/browser-teams/README.md` and `PROTOCOL.md`.

`.call(**kwargs)` accepts `framework,worker_id,role,prompt,continuation,output_schema,model,effort,call_id,max_output_tokens,input_token_limit`. It validates actual framework-expanded UTF8 input/schema against reserved headroom before native Responses dispatch. Calls require `gpt-6.1-sol`, explicit low/medium/high effort, strict structured JSON, `store:false`, retries0, finite timeout and admitted call ID. Results require the resolved model, completed status, no refusal, bounded JSON, original schema and actual nonnegative integer usage. Missing cost staysnull; failed known usage propagates through `AdapterError.usage` for durable accounting. Unknown paid attempts do not auto-retry.

`browser_runner(connect_url,pages,session_id=creation_receipt_id,model_call=admitted_callback)` attaches only to the protected research service's existing owned session. The service passes the session ID from its creation receipt separately from the opaque provider CDP credential. URLs require an exact allowed Browserbase WSS host, TLS443 and no userinfo/fragment; a query `sessionId`, when present, must occur exactly once and match that receipt. The worker does not infer identity from a URL path/query or perform another SDK session lookup. Custom per-run renderers receive the keyword-only identity; ordinary room renderers retain their two-argument contract.

PublicHTTPS sources are DNS/IP pinned and redirect validated before escaped inert cloud rendering. Actual Stagehand inference is admitted through the same workflow ledger; first-page extraction uses two calls, while all at most3pages retain validated text/bounded PNGs. Target-site scripts/forms/login/actions/code stay disabled. The operator-fixed extension UUID is a top-level session-create `extensionId`, with pinned-source hash and metadata readback; requests never select extensions. The [official session schema](https://github.com/browserbase/sdk-node/blob/main/src/resources/sessions/sessions.ts) and [creation API](https://docs.browserbase.com/reference/api/create-a-session) specify separate `id` and `connectUrl` fields; they do not require the URL to encode the ID.

Stagehand sessions alone use paid-plan `keepAlive:true` for their multiple CDP connections, with the same180-second TTL and explicit release/terminal readback; room rendering remains false. The worker retains its inspection socket until SDK attachment settles. [Official keep-alive semantics](https://docs.browserbase.com/platform/browser/long-sessions/keep-alive) do not promise that closing one of several connections is safe without keep-alive. Fixed error codes identify initialization, snapshot render/capture, observe/extract and cleanup phases without storing provider exception text. Original operation failure is retained when cleanup also fails, while the service independently verifies closure.

Research creation drains a shielded durable reservation before cancellation escapes. A cancelled reserve records its new row as cancelled or compensates its newly launched task; shutdown waits admissions. Unknown paid session creation retains ownership through possibleTTL, and exact terminal readback is required for known-session closure. Restart releases known sessions and marks interruption failed. Framework callbacks/live browser connections cannot be persisted or resumed as run state.

Availability means installed/configured capability. Live provider acceptance, verified useful artifact, installed application state and full Agno AgentOS-platform benchmark are separate evidence. Offline source tests run actual frameworks with synthetic admitted responses and a real disposable headless Stagehand extension, with no paid provider/browser calls.
