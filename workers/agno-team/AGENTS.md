# Agno worker boundary

`worker.py` remains an individual credential-free Agno handoff. The experimental
`agentos_probe.py --agentos` uses native AgentOS ASGI/session/JWT lifecycle in a
finite process; it adds no production framework enum or serving port. The parent
owns paid admission, schema validation, token/spend bounds and uncertain receipts.
Never pass model keys, enable provider retries, or start another coordinator.
Keep platform activation claims limited to actual downstream readback.

Use this directory's locked uv environment, never the app venv. Native probe
tests live in `docs/tests/test_agentos_probe.py`; see `docs/AGNO_AGENTOS_PROBE.md`
for execution, private storage, owner isolation and unverified platform limits.
